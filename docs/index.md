## How to Contribute

This wiki is community-driven. Found a mistake? Have a guide to share? Open a PR on [GitHub](https://github.com/homelabindia/wiki).

```bash
# Get started locally
git clone https://github.com/homelabindia/wiki.git
cd wiki
mise trust && mise install
uv run mkdocs serve
```
